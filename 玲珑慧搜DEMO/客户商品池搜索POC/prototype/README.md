# 客户商品池搜索 POC

## 双击启动

回到上一级目录，双击 `启动客户商品池搜索.cmd`。首次启动会自动安装依赖并打开本地页面。

## 本地检索能力

- 仅在浏览器内处理 `.xlsx`，不上传客户材料。
- 自动识别商品名称、品牌/厂家、型号/规格、库存编码等常见列；其余文本列也会进入全文检索。
- 导入后在后台建立本地索引，目标支持单次 1 万条以内材料，避免检索阻塞页面。
- 支持精确命中、跨字段组合、品牌/型号自动提取、型号片段、全半角与单位归一、拼音/谐音、错别字容错、行业同义词与客户别名。
- 没有可靠强匹配时，按相似度返回最多 30 条低置信度“模糊推荐”；商品不足 30 条时展示全部商品。
- 结果会说明命中字段与原因。词典规则位于 `src/search-dictionary.js`，可按客户 POC 材料补充别名，不需要改动检索主逻辑。

## 开发与验证

```powershell
npm.cmd run dev -- --host 127.0.0.1 --port 4173

```
